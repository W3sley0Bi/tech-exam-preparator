# AZ-900 Prep

Exam prep for AZ-900 (Microsoft Azure Fundamentals).

| Folder | What |
|---|---|
| `web/` | Plain HTML/CSS/JS app — open `web/index.html`. Owns the data pipeline (`web/build.py`). See `web/README.md`. |
| `mobile/` | Expo SDK 58 app (iOS + web): same features, native iOS 26 UI, Nimbus mascot, home-screen widget, daily reminder. |

Both apps share the progress format (`az900.v1`), so Export/Import moves progress between them.

## Mobile

```bash
cd mobile
npm run web            # browser
npm run prebuild       # after native config changes (app.json plugins, new native deps)
npm run ios            # debug build on a connected iPhone (needs Metro)
npm run ios:release    # release build on the iPhone — runs without Metro
```

First device install needs Xcode signing (Apple ID / team) and a trusted, connected iPhone. Not Expo Go — the widget and native modules need a real build.

After changing questions or notes in `web/` (`python3 web/build.py`), refresh the bundled data:

```bash
cd mobile && npm run sync-data
```

- Data: `mobile/data/*.json` + `mobile/assets/q`, `assets/notes` (generated by `scripts/sync_data.py`)
- Logic (ported 1:1 from `web/app.js`): `mobile/lib/logic/*`, store `mobile/lib/store.ts`
- Mascot + icon source: `mobile/design/nimbus.py` (regenerates `icon.svg`, splash)
- Architecture contract the agents built against: `mobile/design/CONTRACT.md`

## Question data

Exam questions are **not included** — they are third-party content and not covered by this repo's license.
`web/data/questions.js` and `mobile/data/questions.json` ship as empty stubs; the apps run with notes, lessons and cards only.
To use your own question set, put `page-*.json` files in `web/data/raw/` (format: see `web/build.py`), run
`python3 web/build.py`, then `cd mobile && npm run sync-data`.
