	The question specifically mentions "pay-as-you-go subscription", which is the correct expenditure model name in Azure.

	Pay-as-you-go = Pay for what you use, scale up/down anytime.

5. Your company plans to migrate to Azure.

The company has several departments. All the Azure resources used by each department will be managed by a department administrator.

What are two possible techniques to segment Azure for the departments? Each correct answer presents a complete solution.

NOTE: Each correct selection is worth one point.

A. multiple subscriptions

B. multiple Azure Active Directory (Azure AD) directories

C. multiple regions

D. multiple resource groups


Choices A & D are correct.

A. Multiple subscriptions: Each department can have its own Azure subscription. This allows for isolated billing and resource management, giving each department control over their own resources and costs.

D. Multiple resource groups: Within a single subscription, you can create multiple resource groups, each dedicated to a different department. Resource groups allow you to manage and organize resources based on lifecycle and administrative boundaries, making it easier for department administrators to manage resources specific to their department.
